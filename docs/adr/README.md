# Architecture Decision Records

This directory holds Architecture Decision Records (ADRs) for SomnosSuite.

An ADR captures a decision that has actually been made, its context, and its consequences.

Do not create an ADR for a decision that is still open. Open decisions are tracked in the relevant canonical document (for example [../REQUIREMENTS.md](../REQUIREMENTS.md), [../DOMAIN_ROADMAP.md](../DOMAIN_ROADMAP.md), [../SECURITY_AND_ACCESS.md](../SECURITY_AND_ACCESS.md), or [../OPERATIONS_AND_RECOVERY.md](../OPERATIONS_AND_RECOVERY.md)) until they are decided.
